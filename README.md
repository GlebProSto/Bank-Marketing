# Домашняя работа №3 — Полный цикл ML-проекта: банковский маркетинг

## Ссылка на датасет
Датасет **Bank Marketing** из UCI Machine Learning Repository:  
https://archive.ics.uci.edu/dataset/222/bank+marketing

Данные относятся к кампаниям прямого маркетинга португальского банка. Маркетинговые кампании проводились через телефонные звонки клиентам. Часто требовалось несколько обращений к одному клиенту, чтобы выяснить, оформит ли он срочный банковский вклад («yes») или нет («no»).

## Постановка задачи
**Тип задачи:** бинарная классификация  
**Целевая переменная:** `y` — оформил ли клиент срочный вклад (`yes` / `no`)  
**Основная метрика:** F1-score и ROC-AUC (из-за сильного дисбаланса классов: ≈ 88 % `no` против ≈ 12 % `yes`)

## Что было сделано

### 1. Создание «грязного» учебного датасета
Исходный датабет был намеренно испорчен, чтобы смоделировать реальные условия работы с данными:
- Внесены пропуски (≈ 6 %) в колонки `age`, `balance`, `job`, `marital`;
- Созданы дубликаты записей (≈ 4 %);
- Добавлены выбросы в числовые признаки `age` и `balance`;
- Результат сохранён в `bank-full-dirty.csv`.

### 2. Разведочный анализ данных (EDA)
- Первичный осмотр: размер, типы данных, первые строки;
- Анализ пропусков, дубликатов и выбросов (IQR, clip, визуализация);
- Описательная статистика для числовых и категориальных признаков;
- Корреляционный анализ (Пирсон, Спирмен) и связь категориальных признаков с целевой (хи-квадрат, V Крамера);
- Выявлен сильный дисбаланс классов и правосторонняя асимметрия в признаках `balance`, `duration`, `campaign`.

### 3. Предобработка данных (через `Pipeline` + `ColumnTransformer`)
- Удаление дубликатов;
- Заполнение пропусков: медианой для числовых признаков, модой — для категориальных;
- Масштабирование числовых признаков (`StandardScaler`);
- One-Hot кодирование категориальных признаков (`OneHotEncoder`);
- Разделение на train/test (80/20) со стратификацией по целевой переменной.

### 4. Модели машинного обучения
Были обучена и сравнена три модели:

| Модель | Описание | Почему выбрана |
|--------|----------|----------------|
| **Gradient Boosting** | Ансамбль деревьев решений, последовательно исправляющих ошибки предыдущих итераций (`max_depth=3`, `n_estimators=100`) | Отлично улавливает нелинейные зависимости в табличных данных; ограничение глубины предотвращает переобучение |
| **Linear SVM** | Линейный классификатор с калибровкой вероятностей (`CalibratedClassifierCV`, `class_weight='balanced'`) | Быстрая линейная модель, автоматически компенсирует дисбаланс классов, стабильна при кросс-валидации |
| **XGBoost** | Оптимизированная реализация градиентного бустинга (`scale_pos_weight=10`, `n_jobs=-1`) | Повышенный вес миноритарного класса критически важен для обучения на несбалансированных данных |

Для каждой модели подобран оптимальный порог классификации для максимизации F1-score.

## Итоговые результаты

По совокупности метрик лучшей модели стал **Gradient Boosting**:
- **F1-score:** ≈ 0.61
- **ROC-AUC:** ≈ 0.92

XGBoost и Linear SVM показали сопоставимые, но немного более низкие результаты. Все три модели значительно превосходят случайный классификатор.
